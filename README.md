# Scripts

Miscellaneous scripts I wrote that others may find useful

* [bsa_glaac_ab506_document_analysis](bsa_glaac_ab506_document_analysis/) — Analyze BSA California AB-506 training certificates with AWS Textract (Jupyter)
* [bsa_myscouting_export_unit_pins](bsa_myscouting_export_unit_pins/) — Export Be A Scout unit pin info from my.Scouting to CSV (Python)
* [github_hours](github_hours/) — Infer daily working hours from GitHub commits in an org (Python)
* [google_api_delete_contacts_with_no_phone](google_api_delete_contacts_with_no_phone/) — Delete Google Contacts that have no phone number (Python)
* [google_maps_timeline_export_as_kml](google_maps_timeline_export_as_kml/) — Export Google Maps Timeline days as KML files (Python)
* [google_sheets_export_pdf](google_sheets_export_pdf/) — Export Google Sheets ranges as PDF files (Jupyter)
